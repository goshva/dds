# 11. Нерешённые вопросы

## Технический блокер
**BLOCK-1: SQL Lab недоступен для учётной записи API**
POST /api/v1/sqllab/execute/ → HTTP 403 Forbidden (базы 92 и 76); GET /api/v1/sqllab/ → 403; POST /api/v1/sqllab/estimate/ → 403; POST /api/v1/chart/data → 401 Not authorized; POST /superset/sql_json/ → 404; GET /api/v1/database/ → 200, но count=0. Метаданные (GET /api/v1/dataset/{id}, /api/v1/chart/) доступны.
Влияние: G3 (реальные SQL-проверки) и G4 (связи по данным) не выполнены; фактические данные, NULL-доли, кардинальности и покрытие соединений не измерены.
Требуется: Выдать учётной записи право can_sqllab/can_execute_sql (и видимость баз) либо предоставить отдельный read-only аккаунт SQL Lab.
