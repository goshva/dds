## Комментарии
- **R-1**: Нужен справочник сопоставления сотрудник↔курьер (BD-017).
- **R-2**: Совпадение по дате не доказывает идентичность смены.
- **R-3**: 7021 описывает сборщиков, а не курьеров; для смен курьеров непригоден.
- **R-4**: Требуется проверка покрытия и учёт id_general.
- **R-5**: Источник ограничен последним месяцем.
- **R-6**: Связь заказ↔курьер через день смены требует подтверждения.
- **R-7**: Косвенная связь через день и курьера, без id_shift.
- **R-8**: Связь подтверждена на уровне схемы: pools содержит id_order и id_pool. Покрытие не измерено.
- **R-9**: Связь подтверждена на уровне схемы по имени ключа id_shift; тип в courier_queue не подтверждён.
- **R-10**: Справочник курьеров; сопоставление с id_courier других систем не доказано (BD-017).

## Ключевые выводы
- Ни одна связь не получила статус VERIFIED — нет проверки данными.
- Связь 7802 ↔ 7021 **опровергнута** по построению: у 7021 нет идентификатора курьера.
- Связи 3466 ↔ 4732, 2339 ↔ 4732, 7802 ↔ 4732 **совместимы по типам**, но покрытие не измерено.
- 7802 ↔ 7712 не имеет общего ключа смены.
