# Контракт метрик (metrics contract)

**Статус:** действующий (Stage 3.4.1) · **Версия контракта:** `metrics/v1` · **Дата:** 2026-11-23

Документ фиксирует математические определения метрик качества и правила обработки граничных случаев.

---

## 1. Базовая величина

- Для каждого допустимого наблюдения `i`:

```text
error_i = prediction_i − actual_i
```

Знак ошибки: положительная — завышение, отрицательная — занижение.

## 2. MAE — основная метрика

```text
MAE = mean(|prediction_i − actual_i|)
```

| Свойство | Значение |
|---|---|
| Единица | заказы |
| Направление | меньше — лучше |
| Роль | **основная метрика сравнения моделей** |
| Входные поля | `predicted`, `actual` |

## 3. RMSE

```text
RMSE = sqrt(mean((prediction_i − actual_i)²))
```

Единица — заказы; меньше — лучше; усиливает вклад крупных ошибок. Используется для дополнительной интерпретации, не для единоличного выбора модели.

## 4. WAPE

```text
WAPE = sum(|prediction_i − actual_i|) / sum(|actual_i|) × 100
```

| Случай | Правило |
|---|---|
| `sum(|actual_i|) > 0` | значение в процентах, статус `ok` |
| `sum(|actual_i|) = 0` | **`NOT_AVAILABLE`** (`wape_status = undefined_zero_actuals`); деление не выполняется, ноль не подставляется |
| выборка пуста | `NOT_AVAILABLE` (`wape_status = no_data`) |

## 5. Bias

```text
Bias = mean(prediction_i − actual_i)
```

Интерпретация строго по знаку:

| Знак | Значение |
|---|---|
| `Bias < 0` | модель в среднем **занижает** прогноз |
| `Bias > 0` | модель в среднем **завышает** прогноз |
| `Bias ≈ 0` | среднее смещение небольшое |

Bias **не является** мерой абсолютной ошибки и не заменяет MAE.

## 6. Дополнительные показатели

| Показатель | Формула | Назначение |
|---|---|---|
| `median_abs_error` | медиана `|error_i|` | устойчивость к единичным промахам |
| `max_abs_error` | максимальное `|error_i|` | худший случай на доступной истории |
| `signed_error_sum` | `sum(error_i)` | проверка согласованности с Bias |
| `n` | число допустимых наблюдений | объём выборки |

## 7. Правила расчёта

1. В рамках одной оценки используется **один и тот же** набор допустимых наблюдений.
2. `NULL` **не заменяется** нулём; наблюдение исключается.
3. Выбросы **не удаляются** автоматически.
4. Прогнозы **не округляются** до расчёта метрик; округляется только представление результатов.
5. `NaN` и `Infinity` отклоняются (`validateMetricSet`); при обнаружении набор помечается проблемным.
6. Неявные преобразования типов запрещены.
7. Точность исходных чисел сохраняется; в отчётах — до 4 знаков для метрик и до 2 знаков для процентов.
8. Для каждой метрики фиксируется: формула, входные поля, единицы, обработка `NULL`, поведение на пустой выборке, поведение при нулевом знаменателе, правило округления, интерпретация.

## 8. Сопоставимость метрик

1. Основная метрика выбора — **MAE**.
2. `RMSE`, `WAPE`, `Bias` уточняют интерпретацию.
3. Выбор модели только по одной метрике при существенном ухудшении остальных **не допускается**.
4. Произвольные численные пороги ухудшения не вводятся без отдельного обоснования (см. контракт выбора модели).

## 9. Обязательные величины сравнения

- Помимо метрик, каждая публикация сравнения обязана содержать:

```text
margin_to_runner_up = MAE_best / MAE_second_best − 1
margin_vs_baseline  = (MAE_candidate − MAE_baseline) / MAE_baseline
absolute_mae_difference = MAE_candidate − MAE_baseline
```

Если `MAE_baseline = 0`, `margin_vs_baseline` не рассчитывается и помечается `NOT_AVAILABLE`.

## 10. Связь с реализацией

| Правило | Реализация |
|---|---|
| формулы MAE / RMSE / WAPE / Bias | `src/forecasting/analytics/backtesting/metrics.ts` |
| нулевой знаменатель | `wape_status = undefined_zero_actuals` |
| пустая выборка | `wape_status = no_data` |
| проверка `NaN` / `Infinity` | `validateMetricSet` |
| независимый пересчёт | `recomputeFromRecords`, `verifyMetricsAgainstRecords` |

**Правило двойного расчёта:** итоговые метрики обязаны совпадать с независимым пересчётом из сохранённых прогнозов; расхождение означает недействительность отчёта.

## 11. Ограничения

- Контракт не вводит новых метрик и не изменяет формулы Stage 3.3; денежные метрики и показатели, не относящиеся к целевому ряду, в оценке не используются.
