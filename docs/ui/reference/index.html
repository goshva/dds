Страницы

Состав соответствует маршрутам production-приложения; шестая страница подтверждена кодом (диагностика прогнозирования).

  • Обзор
    История, теневой режим, актуальность источника, график, полнота
  • История заказов
    Показатели периода, фильтры, график, таблица
  • Качество данных
    Полнота, пропуски, календарь, ограничения
  • Происхождение
    Источник, версия, контрольные суммы, актуальность
  • Прогнозы и качество
    Независимые метрики, парное сравнение, ограничения интерпретации
  • Диагностика прогнозирования
    Качество, диагностические записи, провенанс

Ограничения эталонов

  • Нет подключения к API: состояния загрузки, пустоты, ошибки и недоступности показаны статически.
  • Интерактивность ограничена мобильным меню; фильтры и переключатели не выполняют переходов.
  • Расхождения с production фиксируются в отчёте визуального аудита, а не скрываются в эталоне.
