Ограничения диагностики

  • Сохранённый журнал ошибок недоступен (errors.jsonl отсутствует): persisted errors показываются как NOT_AVAILABLE, а не как «0 ошибок».
  • Per-record eligibility reasons не предоставляются: API отдаёт только агрегаты (pendingN / excludedN), без причины по каждой записи.
  • Полная детализация конфликтов не предоставляется: списки duplicate / orphan / snapshotsWithoutReconciliation / actualConflicts в API отсутствуют.
  • Ошибки API ≠ ошибки модели: HTTP-ошибка или not_available источника не означает, что модель ошибочна.
  • pending ≠ failed: прогнозы с будущей target date ожидают появления факта и не являются сбоями.
