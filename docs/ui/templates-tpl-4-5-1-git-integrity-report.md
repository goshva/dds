## 5. Происхождение обнаруженного diff (INFERENCE)

1. Механизм: артефакт формируется командой вида `git diff > diff.txt` (с перенаправлением в сам файл). Поскольку `diff.txt` отслеживается и лежит в рабочем дереве, каждый новый запуск захватывает **удаление предыдущей версии самого себя** — «петля обратной связи».
2. Подтверждение: заголовок `index adacb9e..e69de29` показывает, что один из прошлых запусков зафиксировал состояние, в котором рабочая копия `diff.txt` была пустой (blob `e69de29` — пустой blob), после чего содержимое было записано заново.
3. Динамика внешних изменений (FACT по замерам в разных этапах): 392 780 Б (preflight TPL-4.1.1) → 30 990 Б (TPL-4.2/4.4/4.5) → **490 111 Б** (сейчас). Каждый пересчёт выполнялся вне команд этого агента.
4. Команды этого этапа (`TPL-4.5.1`) не изменяли `diff.txt`: выполнялись только `git rev-parse`, `git status`, `git diff`, `git ls-files`, `git hash-object`, `git cat-file`, `git grep`, `Get-FileHash`; единственная запись — этот отчёт.

## 7. Рекомендации (не выполнялись)

1. **Не восстанавливать автоматически.** При необходимости вернуть зафиксированную версию требуется отдельное разрешение на Git-операцию вида `git restore --source=HEAD --worktree diff.txt` (в этом этапе такие команды запрещены).
2. **Устранить причину петли:** либо формировать артефакт вне репозитория, либо исключать себя из собственного diff: `git diff -- . ':(exclude)diff.txt' > diff.txt` (вариант уже упоминался в материалах TPL-4.2).
3. **Прекратить отслеживание локального артефакта** (отдельная задача с Git-операциями): `git rm --cached diff.txt` + запись в `.gitignore`. Тогда артефакт перестанет появляться в каждом diff репозитория.
4. **Очистка накопленной самоссылочности:** в `HEAD` уже 5 вложенных самозаголовков; разовая перезапись файла «с нуля» (вне репозитория) устранит вложенность, но требует отдельного согласования, так как меняет отслеживаемый файл.
5. **Регламент:** зафиксировать в документации разработки, что `diff.txt` — локальный неотслеживаемый по смыслу артефакт, и не включать его в отчёты о неизменности без указания момента замера.
