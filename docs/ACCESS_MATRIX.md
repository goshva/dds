# Матрица доступа

| Объект | UI URL | REST API | Что даст |
|---|---|---|---|
| Dashboards | `/dashboard/list/` | `GET /api/v1/dashboard/` | Видимые дашборды и метаданные |
| Charts | `/chart/list/` | `GET /api/v1/chart/` | Видимые графики |
| Datasets | `/tablemodelview/list/` | `GET /api/v1/dataset/` | Доступные Dataset и их metadata |

Если UI-страница открывается, а API возвращает 403, это не обязательно ошибка коннектора: UI может использовать другой набор разрешений/legacy ModelView. Сначала фиксируем код ответа и просим администратора разрешить read-only API-доступ. Не используем приватные endpoints или scraping скрытых JSON-объектов как постоянный контракт.

Наличие Dataset не означает, что пользователь может читать исходные строки таблицы. Доступ к chart payload тоже не равен доступу к полному raw history: результат графика может быть агрегирован, ограничен row limit или фильтрами.
