## 3.1 Только чтение

Разрешено:
- GET/read-only запросы к Superset API;
- получение метаданных объектов;
- чтение SQL definition из Superset;

- перезаписывать отчёты предыдущих этапов;
- менять `.env`, пароли, токены и настройки доступа;
- выполнять `git clean`, `git reset --hard`, `git restore`, массовые checkout;
- commit/push без отдельного разрешения.

Если невозможно доказать read-only характер операции — не выполнять её, описать риск.

## 3.2 Секреты и PII

- Не выводить `.env`, пароли, cookies, tokens и Authorization headers.
- Не помещать секреты в логи, отчёты, тесты или Git.
- Не запрашивать пароль в чате.
- Не менять credentials автоматически.
- Не экспортировать имена, телефоны, email, адреса, IP и иные персональные значения.
- Для анализа использовать названия полей, типы, связи и обезличенные агрегаты, если они доступны безопасно.
