## 13. Gate-критерии

**G0 — Repository audit**

Проверены все исходные артефакты.

**G1 — Superset connectivity**

Успешно подтверждён доступ к API и SQL Lab либо документирована конкретная блокирующая причина.

**G2 — Dataset evidence**

Получены актуальные метаданные шести датасетов.

**G3 — Real SQL checks**

Выполнены реальные read-only запросы к доступным источникам.

**G4 — Relationships**

Проверены связи между источниками с измерением доли совпадений.

**G5 — Business decisions**

Все BD-001…BD-024 получили доказательства, статус и вопросы для согласования.

**G6 — Model impact**

Подготовлен перечень изменений к модели 1.5 без изменения DDL.

**G7 — Quality and safety**

Проверены PII, целостность проекта, запреты на запись и локальные тесты.

Итоговый статус:

- PASS — все обязательные проверки выполнены, блокирующих проблем нет;
- PASS_WITH_BLOCKERS — техническая проверка выполнена, но остались бизнес-решения или недоступные источники;
- FAIL — нарушены ограничения, выявлена порча данных или не выполнены обязательные технические проверки.

Не выставлять PASS только на основании наличия отчётов.
