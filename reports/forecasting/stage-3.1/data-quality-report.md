| Вопрос | Ответ |

| Длина истории | 41 календарных дней (2026-10-13 … 2026-11-22) |
| Полных недель (пн–вс) | 5 |
| Простая базовая модель возможна | да (>= 21 дня) |
| Дни недели как признаки возможны | да (>= 2 полных недель) |
| Надёжность недельного профиля | средняя (4–5 полных недель), не высокая |
| Рекомендуемые горизонты | 1, 3, 7, 14 дней |

Число фолдов rolling-origin (оценка, без реализации backtesting):

| горизонт, дней | мин. обучающая история, дней | фолдов |

На этой истории **нельзя** утверждать:

- годовая сезонность
- месячная сезонность
- устойчивость долгосрочного тренда
- поведение в праздники и сезонные пики
- долгосрочная стабильность спроса
- подтверждённая недельная сезонность

Это ограничение объёма данных, а не качества пайплайна: выводы появятся после накопления 12+ недель.

## 11. Ограничения

- период 41 день (менее 6 полных недель): выводы о сезонности невозможны
- 41 день (менее 6 полных недель) не позволяет подтвердить недельную или годовую сезонность: различия средних по дням недели — наблюдаемая закономерность, а не подтверждённый факт.
- один магазин (7745): результаты не переносимы на другие даркстоны без проверки
- бизнес-семантика метрик подтверждена только каталогом метаданных Superset; письменного согласования определений нет
- единицы измерения денежных метрик не подтверждены — суммы не интерпретируются как рубли или копейки
- ratio-метрики нельзя суммировать; знаменатель подтверждён только у части из них
- dimension-поля содержат плейсхолдеры маскирования: возможны коллизии разных сущностей
- почасовых данных нет — внутридневная динамика не анализируется
- кадровые и операционные факторы (явка, пул, ходки, ТМЦ) в наборе отсутствуют
- chart 20209 в основной набор не включён: его семантика (slots = 1) не подтверждена
- профилирование выполнялось read-only: query_only=1, пробная запись отклонена
- дублей по natural key: 0

## 12. Выводы

- Данные технически пригодны для подготовки временного ряда: период непрерывен по календарю, дублей natural key нет, NULL отсутствуют.
- Показатель `qty_orders_delivered` присутствует во всех 5 срезах с одинаковыми дневными суммами — это разные разрезы одного показателя, поэтому нужен канонический срез.
- Ни одна метрика не получает статус READY: бизнес-семантика подтверждена только каталогом метаданных, а не согласованными определениями.
- Готовность к прогнозированию: CONDITIONAL — 9, BLOCKED — 2, READY — 0.
- История 41 дня позволяет проверить только короткие горизонты (1, 3, 7, 14 дней); выводы о сезонности невозможны.

Подробный перечень проблем и действий — в `stage-3.1-findings.md`.
