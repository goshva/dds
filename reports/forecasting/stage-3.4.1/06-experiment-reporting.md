# Этап 6 — Контракт отчётности экспериментов (резюме)

**Документ:** [experiment-reporting-contract.md](../../../docs/forecasting/contracts/experiment-reporting-contract.md) · **Версия:** `reporting/v1`

## Обязательные поля отчёта (19)

- Название · идентификатор эксперимента · дата запуска · версия кода · версия модели · конфигурация · checksum набора данных · целевая метрика · период данных · список горизонтов · режим оценки · `min_train_days` · число прогнозов · число общих наблюдений · метрики · сравнение с baseline · ограничения · известные проблемы · итоговый статус.

## Разделение результатов

```text
PRIMARY:     evaluation_mode = step-exact, min_train_days = 28
SENSITIVITY: evaluation_mode = step-exact, min_train_days = 21
REFERENCE:   evaluation_mode = cumulative
```

Обязательно различаются: основной результат, sensitivity analysis, справочные cumulative-результаты, недоступные модели (`NOT_AVAILABLE`), некорректные эксперименты (`INVALID`), эксперименты без сопоставимости (`INCONCLUSIVE`). Три режима не объединяются в одну таблицу без явного обозначения.

## Счётчики покрытия

- `origins_total`, `origins_evaluated`, `forecasts_expected`, `forecasts_generated`, `forecasts_missing`, `actuals_missing`, `common_evaluation_count` — с обязательной формулой: число пар `(origin, target)` на горизонт, где у всех доступных моделей есть прогноз и есть факт; при агрегировании указывается, что это сумма, а не число уникальных дат.

## Обязательные формулировки

- Cumulative-результат не называется качеством прогноза на `h`-й день.
- Утверждение «модель лучше» без `margin_to_runner_up` запрещено; при малом отрыве используется формулировка «модели неразличимы на доступной истории».
- `NOT_AVAILABLE` не называется ошибкой модели.
- Результаты при статусе семантики `PROVISIONAL` помечаются как технические.

## Преемственность

- Предыдущие версии отчётов сохраняются в `archive/`, удаление запрещено, изменения фиксируются отдельным документом. Пример: `reports/forecasting/stage-3.3/archive/pre-3.3.6/`.

## Связь с реализацией

- `src/forecasting/analytics/backtesting/reports.ts` (секции режимов, `COMMON_SET_FORMULA`), артефакты `3.3.5-*` (детализация, покрытие, сравнение, утечка, воспроизводимость).
