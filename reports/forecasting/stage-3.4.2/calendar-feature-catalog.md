## Обоснование статусов

| feature_name | обоснование |
| --- | --- |
| day_of_week | базовый признак; распределение по дням недели проверено описательно |
| is_weekend | различие рабочих и выходных дней наблюдаемо, но переносы делают признак неполным без производственного календаря |
| month / quarter / week_of_year | описательная сезонность наблюдаема; для утверждений о многолетней сезонности истории недостаточно |
| month_boundary_flags | требует проверки на данных; границы периода могут совпадать с праздниками |
| is_statutory_holiday | даты подтверждены вторичным источником со ссылкой на ст. 112 ТК РФ; официальный первоисточник не проверялся |
| official_day_off / working_saturday | для 2025 переносы подтверждены вторичным источником; 2024 и 2026 не проверялись → UNVERIFIED |
| days_to_holiday / days_after_holiday | эффект близости праздника описательно проверяется; требует подтверждения на большем числе периодов |
| long_weekend_id / position_in_long_weekend | требует подтверждённых переносов по всем годам истории |
| season | доступно 2 неполных года: сезонность описательна, но не подтверждена статистически |
| temperature / precipitation / snow / ice / extreme_heat / extreme_cold | без подтверждённого источника прогноза погоды на дату origin использование приведёт к утечке будущего |
| school_holiday | требуется официальный источник по годам истории; без него — только гипотеза |
| city_event / road_closure / mass_departure | нет подтверждённого источника и доказательства влияния на доставку конкретного магазина |
